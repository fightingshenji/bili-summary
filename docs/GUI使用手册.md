## 1. 软件简介

**视频总结助手** 把 B站视频自动转化为结构化总结报告：

- 自动抓取字幕（CC 优先、AI 兜底）→ DeepSeek 大模型提炼
- 输出 Markdown 报告：一句话总结 / 核心观点(带时间戳) / 章节脉络 / 金句 / 博主风格 / 可执行结论
- 附带：全文逐字稿、批量总结、多分P合并、博主观点跨视频跟踪

**文件组成**（`bili-sum/` 文件夹，整体拷贝）：

```
bili-sum/
├── bili-sum.exe      ← 双击启动
├── _internal/        ← 依赖库（勿动）
├── data/             ← 你的配置/观点库/报告（见 §10）
└── 使用说明.txt
```

> ⚠️ 必须整个文件夹一起拷贝，只拷 exe 无法运行。

## 2. 快速开始（30秒上手）

1. 双击 `bili-sum.exe`（启动约 1 秒）
2. 首次使用先配置（见 §8）：
   - **设置** 页 → 粘贴 **DeepSeek API Key**
   - **设置** 页 → 粘贴 **B站完整 Cookie**
3. **首页** 粘贴视频链接 → **开始总结**
4. 完成后点 **打开报告**

## 4. 首页 · 单视频总结

**操作流程**：粘贴链接 → 选分P → 点开始 → 看日志 → 打开报告。

| 控件 | 说明 |
|---|---|
| 视频链接 | 完整链接 / BV号 / av号 均可；带 `?p=N` 的链接自动只处理该分P |
| 分P（留空=第1P, 0=全部） | `留空` 总结第1P；`0` 合并所有分P；`1,3` 指定多个P |
| ☐ 仅字幕不调LLM | 只抓字幕存全文，不调大模型（免费）；产出为逐字稿而非报告 |
| ☐ 忽略缓存 | 强制重新抓取+总结（费时费钱，平时勿勾） |
| ☐ 跳过观点入库 | 本次总结不进博主观点库（总结老视频推荐勾选） |
| 开始总结 / 取消 | 后台运行；日志实时滚动，可随时取消 |
| 字幕覆盖 | 显示"字幕覆盖到几点 / 完整度"——老视频字幕不全时显示 ⚠️ 不完整 |
| 打开报告 / 打开目录 | 完成后亮起；打开 Markdown 报告或所在文件夹 |

**示例**：
- 总结单个视频：粘贴 `https://www.bilibili.com/video/BV1uiuU6LEYF` → 开始总结
- 多分P视频全总结：分P填 `0`（如"干货篇01"的 P1-P4 合并成一份完整报告）
- 只想看文字稿：勾选"仅字幕不调LLM" → 秒出逐字稿

## 5. 批量页 · 多视频批量总结

- 文本框**每行一个链接**，`#` 开头为注释（# 行不执行）
- **导入文件**：载入已有的 txt 批量列表
- **开始批量**：逐个自动总结
  - 单个失败**不中断**，其余继续
  - 进度条显示 `当前 / 总数`
- 底部红色文字列出**失败项**（链接 + 原因）

**示例列表**：
```
# 本周要总结的
https://www.bilibili.com/video/BV1uiuU6LEYF
BV1ZRgX6rE3p
BV1nK4y1X7Tb?p=2
```

## 6. 跟踪页 · 博主观点跟踪

自动追踪博主观点，跨视频看"观点演变"。

**使用步骤**：
1. 左侧列表显示已跟踪博主（视频数/观点数）——总结视频后自动入库
2. **点击博主** → 展开其视频列表（每条带日期，默认 ☑ 勾选参与）
3. **点击视频可取消勾选**——排除时间跨度过大的老视频（如 2021 年干货篇）
4. 点 **生成观点报告** → 只分析勾选视频，输出演变报告：
   - 视频时间线 + 逐期观点明细
   - 主题演变（同主题跨期对比、变化点）
   - 值得注意的信号（观点转折/强化）

**小贴士**：跟踪报告生成后点"打开报告"查看完整 Markdown；勾选不同视频组合可对比不同时间段的观点。

## 7. 已总结页 · 历史记录

- 列出所有已总结视频（标题 / UP主 / 日期 / 字幕覆盖）
- **字幕覆盖三态色**：🟢 完整 ｜ 🟡 部分 ｜ 🔴 无/极少
- 选中后：
  - **打开报告**：查看该视频总结
  - **重新总结**：自动带"0=全部分P"跳转首页，点开始即可

## 8. 设置页 · 配置

| 项目 | 操作 |
|---|---|
| B站 Cookie | 显示已配置项数；点 **手动粘贴Cookie JSON** 粘贴完整 Cookie（格式见下） |
| DeepSeek API Key | 粘贴 → 保存（写入 `data/.env`） |
| 数据目录 | 显示当前位置（exe 模式 = exe 同级 `data/`），整体拷贝可迁移 |

**B站 Cookie 获取（AI字幕必需，实测必须完整Cookie）**：

1. Edge/Chrome 打开 `bilibili.com` 并**登录**
2. `F12` → **网络(Network)** → `F5` 刷新 → 点任一请求
3. **请求标头** 里找到 **Cookie** 一整行 → 全选复制（去掉 `Cookie: ` 前缀）

粘贴格式（`键=值; 键=值`，约 25-30 项）：
```
buvid3=xxx; buvid4=xxx; b_nut=xxx; bili_ticket=xxx; SESSDATA=xxx; ...
```

> ⚠️ **保存 Cookie / Key 后必须重启程序**（配置在启动时加载）。

**常见配置错误**：
- ❌ 只贴 `SESSDATA` 的一个值（无键名、无其他项）→ 会报"未解析到任何 Cookie 项"
- ✅ 整串 `buvid3=...; buvid4=...; SESSDATA=...` 粘贴

## 9. 常见问题

| 问题 | 解答 |
|---|---|
| 提示缺少 Cookie / 字幕为空 | 设置页重新粘贴**完整 Cookie** → 重启程序 |
| 老视频总结内容少 | 老视频 AI 字幕不全属正常（报告会提示覆盖比例）；可勾选"跳过观点入库"避免污染跟踪 |
| 杀毒软件报毒 | PyInstaller 打包常见误报 → 加入白名单即可 |
| 启动要 10-20 秒 | 那是单文件版；本版（文件夹版）约 1 秒。确认拷贝了整个文件夹 |
| 已总结列表没刷新 | 点"刷新"按钮 |
| 批量中途失败 | 失败项不中断，红色文字列出，其余继续 |
| 总结按钮点了没反应 | 可能已有任务在跑；先点"取消"或等它完成 |
| Cookie 失效 | 重新按 §8 获取替换 |
| 提示"视频不存在" | 链接错误 / 视频已删除 / 审核中 |

## 10. 隐私与安全

- **敏感数据仅存本机** `data/` 目录：`.env`（Key）、`bilibili_cookies.json`（Cookie）、`reports.db`（观点库）、`output/`（报告）
- **不要直接压缩 `bili-sum/` 文件夹分享**——会泄露你的 Key/Cookie/报告！
- 分享请使用"纯净分享版"（`bili-sum_share.zip`，已剔除全部个人数据），对方自行配置
- 仅供个人学习研究使用，请勿商用/传播抓取内容
